COMO EXECUTAR O MODO AULA

1. Abra a pasta no VS Code.
2. Instale a extensão "Live Server" (Ritwick Dey), se ainda não tiver.
3. Clique com o botão direito em index.html > "Open with Live Server".
4. Abra a página Blog pelo menu.

IMPORTANTE
O arquivo noticias.json é a fonte dos posts. Ao adicionar uma nova notícia, o site a ordena automaticamente pela data e mostra as mais recentes primeiro.

Ao abrir index.html diretamente com duplo clique (file://), alguns navegadores bloqueiam o carregamento de JSON por segurança. O projeto agora possui um fallback para não deixar a página vazia, mas para visualizar automaticamente qualquer nova alteração no noticias.json use Live Server.
